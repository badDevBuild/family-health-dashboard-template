# 设计系统

目标是“温暖、可信、平静”，像家庭健康资料夹，而不是医院监护仪。

- 正文字号不小于 16px，触摸目标不小于 44px。
- 页面背景 `#FAFAF8`，主文字 `#2C2824`，主色 `#3B9B6F`。
- 正常状态用柔和绿色；需要关注用琥珀色 `#D4910A`；需要尽快咨询用赭石色 `#C75C3A`，避免警报式纯红。
- 卡片圆角 16px，内部留白 16px，卡片间距 12px，章节间距 32px。
- 动效只服务于状态变化，持续 150–250ms，不使用弹跳效果。
- 移动端单列，最大内容宽度 430px；平板可扩展到 768px。
- 首屏优先显示最重要的结论，正常信息低调呈现，详情按需展开。

任何界面修改都应保持对老人友好、高对比、低焦虑，并验证真实文本长度下的换行和可读性。
